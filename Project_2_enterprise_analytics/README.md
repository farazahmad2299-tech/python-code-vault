# Employee Salary Calculator

This is a simple Python project I made while learning Python basics. 

## What it does:
- Shows a welcome message and company details.
- Takes input for 4 employees (names and salaries).
- Automatically fixes employee names using `.title()`.
- Calculates total salary, highest salary, lowest salary, and average using basic functions (`sum`, `max`, `min`, `len`).

## Topics used:
- Variables & Input
- Lists and Tuples
- Basic math and built-in functions

## How to run:
Open your terminal or VS Code and run this command:
```bash
python enterprise_analytics.py
